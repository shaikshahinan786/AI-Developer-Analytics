# 🚀 AI Developer Analytics

> Track & Analyze Developer Productivity with AI Insights

### 📌 Overview
This dashboard analyzes developer activity - commits, AI tool usage (Copilot, Claude, Cursor), productivity trends.

### ✨ Features
- Developer-wise AI tool usage tracking
- Cost & Token analytics
- Weekly productivity trends

### 🛠️ Tech Stack
Python, Pandas, Streamlit, Data Visualization

### 🚀 How to Run
git clone https://github.com/shaikshahinan786/AI-Developer-Analytics.git
pip install -r requirements.txt
streamlit run app.py
